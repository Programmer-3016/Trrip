## 🛠️ Tech Stack & Design System
- **HTML5 & Vanilla JavaScript** for reactive state transitions and zero-dependency prototype performance.
- **Tailwind CSS** with a custom destination-inspired palette (Teal `#00685f`, Heritage Emerald `#006c4a`, Warm Amber `#825100`).
- **Typography:** Plus Jakarta Sans (Headings & Numbers) + Inter (Legibility & Metadata).
- **Icons:** Google Material Symbols Outlined.
- **Images:** Authentic Jaipur local delicacies and heritage dining photography.
